# ClassCircle

ClassCircle is an academic management app built with Flutter. It aims to help university students manage their study groups, track assignments, chat with classmates, and stay organized throughout the semester.

## 🚀 Features

- Feature 1 User authentication with two-factor OTP verification (Login & Signup)
- Feature 2 Study group management — join, leave, create, and switch delivery modes (Face-to-Face / Online)
- Feature 3 Real-time chat with classmates and study group members
- Feature 4 Assignment tracking with Pending, Submitted, and Graded tabs
- Feature 5 Task progress tracking with dynamic progress bars
- Feature 6 Theme changing — full Dark Mode and Light Mode support
- Feature 7 Profile editing with photo upload and academic details

## 🛠️ Tech Stack

- Flutter (Dart)
- image_picker for profile photos
- Material Design 3
